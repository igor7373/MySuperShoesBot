# Мой магазин обуви - Telegram Bot

Полнофункциональный Telegram-бот для интернет-магазина обуви с системой управления каталогом, заказами и живым чатом с клиентами.

## Описание проекта

Это Telegram-бот, который предоставляет полный функционал интернет-магазина обуви:
- Просмотр каталога товаров с фото/видео
- Поиск обуви по размеру
- Корзина и оформление заказов
- Интеграция с Новой Поштою и Укрпоштою
- Живой чат с администраторами
- Автоматические ответы через FAQ базу
- Управление товарами и заказами

## Технологии

- **Python 3.12**
- **python-telegram-bot[job-queue]** - Telegram Bot API с поддержкой задач по времени
- **SQLite3** - база данных для хранения товаров, заказов и истории
- **asyncio** - асинхронное программирование
- **APScheduler** - автоматическое управление таймерами бронирования

## База данных

Проект использует SQLite с следующими таблицами:

### products
Каталог товаров магазина
- `id` - уникальный идентификатор
- `file_id` - ID файла в Telegram (фото/видео)
- `price` - цена товара
- `sizes` - доступные размеры (JSON)
- `is_sold` - статус продажи
- `message_id` - ID сообщения в канале
- `insole_lengths_json` - длина стельки для каждого размера

### faq
База знаний с автоответами
- `id` - идентификатор записи
- `keywords` - ключевые слова для поиска (JSON)
- `answer` - текст ответа

### live_chats
Сессии живого чата с администраторами
- `user_id` - ID клиента
- `admin_id` - ID администратора, обрабатывающего запрос
- `status` - статус чата (waiting/active/completed)
- `last_update` - время последнего обновления

### message_history
История всех сообщений для логирования
- `id` - уникальный идентификатор
- `user_id` - ID пользователя
- `message_text` - текст сообщения
- `sender_type` - тип отправителя (user/admin)
- `timestamp` - время отправки

### customers
Данные клиентов
- `user_id` - ID в Telegram
- `full_name` - полное имя
- `phone_number` - номер телефона

### orders
Заказы клиентов
- `order_id` - уникальный номер заказа
- `customer_user_id` - ID клиента
- `delivery_address` - адрес доставки
- `ttn` - номер ТТН (трек-номер)
- `status` - статус заказа
- `created_at` - дата создания

### order_items
Товары в заказе
- `item_id` - идентификатор позиции
- `order_id` - номер заказа
- `product_id` - ID товара
- `size` - выбранный размер
- `price_at_purchase` - цена на момент покупки

## Основные функции

### Для клиентов

#### Поиск и просмотр товаров
- Поиск обуви по размеру
- Просмотр каталога с пагинацией (9 товаров на странице)
- Просмотр фото/видео товара
- Информация о длине стельки для каждого размера (28-48)

#### Покупка
- Добавление товаров в корзину
- Выбор размера из доступных
- Просмотр и редактирование корзины
- Выбор типа оплаты (предоплата/полная оплата)
- Отправка подтверждения оплаты (скриншот)

#### Оформление заказа
- Ввод ФИО и номера телефона
- Выбор способа доставки (Новая Пошта / Укрпошта)
- Указание адреса и номера отделения
- Получение подтверждения заказа

#### Система бронирования
- Товары бронируются на **30 минут** (10:00-19:00)
- Товары бронируются **до 10:00 следующего дня** (после 19:00 или до 10:00)
- Автоматическое снятие брони по истечении времени

#### Живой чат
- Автоматические ответы через FAQ базу
- Отправка запросов администраторам
- Общение с менеджером в режиме реального времени
- История диалогов

### Для администраторов

#### Управление товарами
- Добавление новых товаров (фото/видео)
- Выбор доступных размеров (28-48)
- Установка цены
- Автоматическая публикация в канал магазина
- Редактирование цены товара
- Редактирование размеров
- Переопубликация товара в канал
- Удаление товара из каталога

#### Управление FAQ
- Добавление записей с ключевыми словами
- Просмотр всех записей FAQ
- Удаление записей

#### Обработка заказов
- Получение уведомлений о новых заказах в канал
- Добавление номера ТТН (трек-номера)
- Изменение статуса заказа (picked/returned)

#### Живой чат
- Получение запросов клиентов
- Возможность взять чат в работу
- Общение с клиентом
- Просмотр истории диалога с клиентом
- Завершение и очистка чата

#### Настройки
- Изменение платежных реквизитов
- Создание постов с кнопкой "Найти свой размер"

## Команды бота

### Для клиентов
- `/start` - начало работы с ботом
- `/start find_size` - поиск обуви по размеру
- `/start buy_{product_id}` - выбор размера товара
- `/start buy_{product_id}_{size}` - прямая покупка с указанным размером

### Для администраторов
- `/addproduct` - добавить новый товар в каталог
- `/catalog` - показать весь каталог товаров
- `/delete` - удалить товар из каталога
- `/add_faq` - добавить запись в FAQ базу
- `/list_faq` - показать все записи FAQ
- `/set_details` - изменить платежные реквизиты
- `/clear_chat {user_id}` - очистить сессию чата с клиентом
- `/endchat` - завершить активный чат
- `/get_history {user_id}` - получить историю диалога с клиентом
- `/createbuttonpost` - создать пост с кнопкой поиска

- `DISPATCH_CHANNEL_ID` - ID канала для обработки отправок

**Рекомендация по безопасности:** Используйте переменные окружения вместо хранения чувствительных данных в файле конфигурации.

База данных создается автоматически при первом запуске бота.


## Цикл жизни заказа

1. **Выбор товара** - клиент находит нужную обувь по размеру
2. **Добавление в корзину** - выбирает размер и добавляет товар
3. **Оформление оплаты** - выбирает тип оплаты и получает реквизиты
4. **Бронирование** - товар бронируется на 30 минут (или до 10:00)
5. **Подтверждение оплаты** - клиент отправляет скриншот
6. **Ввод данных** - ФИО, телефон, город
7. **Выбор доставки** - Новая Пошта или Укрпошта
8. **Подтверждение** - заказ отправляется администраторам
9. **Обработка** - администратор добавляет ТТН
10. **Отправка** - статус меняется на "picked" или "returned"

## Особенности реализации

### Система резервирования
Товары автоматически бронируются при оплате:
- В рабочее время (10:00-19:00) - на 30 минут
- Вне рабочего времени - до 10:00 следующего дня
- Используется JobQueue для автоматического снятия брони

### FAQ и живой чат
- При получении сообщения от клиента бот ищет совпадения в FAQ базе
- Если ответ найден - отправляется автоматически
- Если нет - создается запрос на живой чат
- Администраторы получают уведомление и могут взять чат в работу
- Все сообщения логируются в базу данных

### Deep Links
Поддержка прямых ссылок для быстрого доступа:
- `t.me/botname?start=buy_123` - выбор размера товара #123
- `t.me/botname?start=buy_123_42` - покупка товара #123 размера 42
- `t.me/botname?start=find_size` - переход к поиску по размеру

### Галерея товаров
- Результаты поиска выводятся по 9 товаров на странице
- Кнопки навигации "◀ Назад" и "Вперед ▶"
- Кнопка "К корзине" всегда доступна

### Каналы Telegram
Проект использует три канала:
1. **Публичный канал** - для публикации каталога товаров
2. **Канал заказов** - для уведомлений о новых заказах
3. **Канал отправок** - для обработки и отслеживания доставок

## Таблица размеров

Бот использует таблицу соответствия размеров и длины стельки (28-48):
- Размер 28 = 20.0 см
- Размер 29 = 20.5 см
- ...
- Размер 48 = 30.5 см

Эта информация отображается клиентам при выборе размера.
